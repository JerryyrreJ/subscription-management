卸载 App 后，订阅通常还会继续扣费。要停止续费，需要找到这笔订阅的扣款渠道，再按对应流程取消。

先查清楚是谁在收款：微信、支付宝、Apple、Google Play，还是商家自己。取消后，到对应的订阅或自动扣款列表确认状态。

可以用手机备忘录或表格记录，边查边填。如果订阅比较多，先查常用的支付渠道，再补上银行卡和邮件里的记录。

整个过程分为几步：

1. 记下：服务名、金额、币种、周期、**扣款渠道**、下次扣款日（能看到的话）、你打算怎么处理。
2. 打开微信、支付宝、Apple 订阅、Google Play 订阅；如果用过银行卡或运营商代扣，也一起检查。
3. 找到订阅对应的取消入口，不要只卸载 App。
4. 每条选保留、取消，或先提醒自己过几天再定。
5. 取消后回列表确认状态，并在下一个预计扣款日检查账单。

## 钱到底从哪个渠道扣？

账单上写「爱奇艺」「腾讯视频」还好认。有时却是「APPLE.COM/BILL」、一串商户简称，或微信里一条「商户扣费」。同一个视频会员，可能扣在微信、支付宝、Apple 或 Google——只按 App 名找，会漏。

逐个检查扣款渠道，可以找到那些已经卸载、但仍在续费的 App。

## 先建一张表

列可以很简单：

| 字段 | 备注 |
| --- | --- |
| 服务 / 会员名 | 账单名和 App 名经常对不上 |
| 金额 | 写实际扣的数 |
| 币种 | CNY / HKD / USD 都行 |
| 周期 | 周 / 月 / 季 / 年 |
| 下次扣款日 | 看到就记；看不到先写「未知」 |
| **扣款渠道** | 微信 / 支付宝 / Apple / Google / 银行卡 / 运营商 / 其他 |
| 是否试用 | 记下试用结束和开始收费的日期 |
| 决策 | 保留 / 取消 / 提醒 |
| 取消结果 | 列表里是否显示已取消 / 已解约 |

### 一张填写示例

以下金额仅用于演示表格，不代表各服务的实际价格。

| 服务 | 金额 | 币种 | 周期 | 扣款渠道 | 决策 |
| --- | --- | --- | --- | --- | --- |
| 某视频会员 | 25 / 月 | CNY | 月 | 支付宝免密 | 取消 |

表里也要记下已经卸载的 App，例如上面的游戏通行证。是否继续扣费，要以订阅状态为准。

## 微信：自动续费 / 扣费服务

路径因版本略有差别，以你手机显示为准。常见走法：

**我 → 服务 → 钱包 → 支付设置 → 自动续费**

有的版本入口叫「自动续费 / 免密支付」或「扣费服务」。找不到就在支付设置页里搜「自动」「扣费」。

公开说明可看[微信开放社区这篇关于关闭自动扣款的讨论](https://developers.weixin.qq.com/community/minihome/doc/000a4882d2c5d01b22a2232ae66c00)。菜单名称可能随版本调整，以 App 显示为准。

点进不想要的项目，关掉扣费，确认列表里已经是关闭 / 解约状态。

如果服务是通过 Apple 应用内购买开通的，微信自动扣费列表可能查不到。可以继续到 Apple 的订阅列表查找。

## 支付宝：免密支付 / 自动扣款

常见走法（以你手机为准）：

**我的 → 设置 → 支付设置 → 免密支付 / 自动扣款**

有的版本写成「自动续费」。列表里把不用的关掉或解约，确认状态已变。

取消自动续费后，已付费的会员权益通常会保留到本期结束。App 里仍显示会员，不一定是取消失败；应查看续费状态和权益到期日。退款需要另行按商家规则申请。

如果不确定是否取消成功，可以同时核对商家的续费状态和支付宝的扣款授权。仍显示有效时，向商家确认是否还会扣下一期费用。

## Apple：App Store / Apple 账户订阅

常见走法：

**设置 → 点你的姓名 → 订阅 → 选中项目 → 取消订阅**

细节和排错以官方为准：  
[如果要取消 Apple 的订阅](https://support.apple.com/zh-cn/118428)

列表里找不到时，可以查：

- 邮箱有没有「Apple 提供的收据 / 发票」  
- 是不是登错 Apple 账户  
- 是不是家庭共享里别人付的  
- 是不是其实微信、支付宝或运营商在扣（官方也写了：没有 Apple 收据时，可能是别的公司收费）

如果不打算在试用结束后付费，请提前取消。Apple 的说明通常要求至少提前 **24 小时**，具体时限以订阅页面和官方帮助为准。

取消续费通常不会退还本期费用，已付费的使用时间一般会保留到周期结束。试用订阅的权益何时结束，请查看取消页面的提示。

## Google Play

常见走法：

**Google Play → 付款与订阅 → 订阅 → 取消**

电脑上也可打开 play.google.com 管理订阅。

官方说明：  
[在 Google Play 上取消、暂停或更改订阅](https://support.google.com/googleplay/answer/7018481?hl=zh-Hans)

**卸载应用不会取消订阅。** 请进入订阅列表操作，并确认状态已变为取消。

## 可选：银行卡连续扣款 / 运营商代扣

银行或信用卡 App 里有时有「连续扣款」「商户管理」；运营商套餐、增值业务也会代扣。对照账单检查是否有定期扣款；看不懂的项目可以向银行或运营商客服查询。

经运营商开通的 Apple 类订阅，Apple 官方也说要找运营商处理。

## 每条怎么选：保留 / 取消 / 提醒

**保留：** 还在使用，费用可以接受，也没有重复购买。记下下次扣款日。

**取消：** 已经不用、重复购买，或不准备在试用后付费。到对应扣款渠道取消，并确认续费状态。

**暂时不决定：** 试用还没结束，或家庭共享的订阅需要商量，可以先设日历提醒。月付可提前一周、年付可提前两三周，给自己留出处理时间。

## 取消后，检查下一期账单

回到列表，确认状态真是已关闭 / 已解约 / 已取消。

保存取消确认信息，并在**下一个预计扣款日**前后检查账单。如果仍然扣款，先核对扣款时间、账号和渠道，确认是否有另一笔订阅。然后带上扣款记录和取消确认信息，联系商家或支付客服处理。

## 试用快到期时

开通试用时就记下结束日期，并提前几天设置提醒。如果不准备续订，在平台要求的截止时间之前取消，避免等到最后一天才处理。

## 想大概知道花了多少

可以把年付金额除以 12，和月付订阅放在一起比较。例如，每年 120 元的订阅，折合每月 10 元，但续费当天仍会一次扣除 120 元。

不同币种先分别统计；如果要合计，统一换算后再相加。这样既能看每月大致支出，也能知道哪些月份会有较大的扣款。

## 多久再看一遍？

整理完后，每个月查一下新试用和新增扣款，每年再完整检查几次。更换银行卡、Apple / Google 账号，或调整家庭共享订阅时，也可以顺手更新记录。

## 整理后，怎么继续记录

订阅不多时，继续维护这张表、配合日历提醒就够了。如果想集中查看支出和续费日期，也可以把保留的项目记到 [Subscription Manager](https://app.steadyrenew.com)。它支持中文、多币种和续费提醒，不需要绑定银行。

录入时可以用截图或收据辅助填写，再核对金额和日期。取消订阅仍需到对应平台操作，应用不会代你解约，也不会自动读取支付账单。

## FAQ

### 怎么查看并关闭微信 / 支付宝 / Apple 的自动续费？

微信：钱包 → 支付设置 → 自动续费（或近义入口）。支付宝：设置 → 支付设置 → 免密支付 / 自动扣款。Apple：设置 → 点姓名 → 订阅。菜单名因版本会变，以手机显示为准。Apple 完整说明见[官方帮助](https://support.apple.com/zh-cn/118428)。

### 关闭后还在扣费怎么办？

先核对扣款时间和取消生效时间，再查是否有另一个账号或渠道开通了相同服务。保存相关记录，联系商家或支付客服确认原因。

### 怎么取消 Apple 订阅？

设置 → 姓名 → 订阅 → 取消。详见 [Apple 官方说明](https://support.apple.com/zh-cn/118428)。找不到就查收据、账户、家庭共享，或是否由其他渠道收款。

### 怎么取消 Google Play 订阅？卸载算取消吗？

Play → 付款与订阅 → 订阅 → 取消；或用网页管理。[官方说明](https://support.google.com/googleplay/answer/7018481?hl=zh-Hans)。卸载不算取消。

### 卸载 App 还会扣费吗？

如果订阅仍在自动续费，就可能继续扣款。需要到对应的订阅或扣款列表取消。

### 只在 App 里关自动续费够不够？

要看这笔订阅的扣款渠道。按 App 的取消流程操作后，可以到对应支付渠道或商店订阅列表核对状态。

### 免费试用到期前怎么提醒自己？

开通时记下试用结束日期，提前几天设日历提醒，并在平台要求的截止时间前取消。
