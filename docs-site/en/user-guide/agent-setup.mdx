# Connect your agent

## Connect in three steps

<Steps>
  <Step title="Create a Developer API key">
    Sign in and open **Settings → API & MCP**. Create a dedicated key for your assistant:
    choose **Read & write** to list, create, update, and delete subscriptions, or **Read only** for safe querying and spend analysis.
    The full `subm_…` secret is shown only once and never expires automatically until revoked.
  </Step>
  <Step title="Copy to Agent (or copy a manual client snippet)">
    Choose **MCP · recommended** or **API only**, then click **Copy to Agent**.
    By default the generated prompt contains no secret; right after creating a key, you can optionally check **Include newly created key in this copy** for a trusted agent.
    Prefer manual configuration? Expand **Manual client config** on the same card for ready-to-paste snippets for Claude Code, Claude Desktop, Cursor, and Codex.
  </Step>
  <Step title="Verify the connection">
    Ask the agent to list your subscriptions (it will verify access with a read-only query without creating test data; an empty list also counts as success).
    You can also click **Test API connection** directly inside **Settings → API & MCP** to verify any new or saved key—testing updates the key’s **Last used** timestamp immediately.
  </Step>
</Steps>

After connecting, try natural prompts like:

- *"Which subscriptions or free trials renew in the next 14 days?"*
- *"Summarize my monthly spend by currency and category."*
- *"Add ChatGPT Plus at \$20/month renewing on 2026-07-17."* (With a `write` key, the agent summarizes and asks for confirmation first.)
- *"Delete the duplicate Netflix tracking entry."* (With a `write` key, the agent confirms exact name and `id` first.)

## Choose how to connect

| Method | Best for | How it works |
| --- | --- | --- |
| **Remote Streamable HTTP MCP** (`/api/mcp`) | Claude Code, Cursor remote MCP, ChatGPT / web Claude connectors | Connect directly to `https://steadyrenew.com/api/mcp` (`POST` with `Authorization: Bearer subm_…`) — **zero local installation or Node.js required** |
| **Local stdio MCP** (`/downloads/steadyrenew-mcp.mjs`) | Claude Desktop, Cursor local stdio, Codex (`config.toml`), OpenCode | Download one self-contained `.mjs` file (Node.js 20+) and run it via `node` with `SUBSCRIPTION_MANAGER_API_KEY` |
| **Direct `/api/v1` REST API** | Cron scripts, custom backends, HTTP-capable agents without MCP | Call `/api/v1/*` directly using `/agent/openapi.yaml` and `/agent/ai-tools.json` |

> [!TIP]
> **Download MCP** on **Settings → API & MCP** also provides a backwards-compatible standalone npm tarball (`/downloads/subscription-manager-mcp.tgz`). For most local stdio setups, downloading `/downloads/steadyrenew-mcp.mjs` directly (`curl -fsSL https://steadyrenew.com/downloads/steadyrenew-mcp.mjs -o ~/.steadyrenew/mcp/steadyrenew-mcp.mjs`) is faster and avoids npm workspace install quirks.

## Plan limits & scope behavior

- **Rate & key limits**: Both Free and Premium accounts allow up to **5 active keys** and **60 requests / minute** per account (shared across keys). Keys never expire automatically.
- **Read-only keys**: Selecting **Read only** generates a `["read"]` key and tailors **Copy to Agent** so the assistant knows upfront not to attempt writes.
- **Premium analytics**: `get_spend_summary` works on all plans; `find_duplicate_subscriptions` and `get_optimization_suggestions` require **Lifetime Premium** (`403 premium_required` on Free).
- **Web-only settings**: Deleting a record never cancels a subscription with the external merchant. Bark push URLs, test pushes, `timeZone`, `locale`, and category catalog edits stay in the web app (see [Reminders](/en/user-guide/reminders)).

## Troubleshooting

| Symptom | What to do |
| --- | --- |
| `401` (`authentication_required` / `invalid_api_key`) | Verify the full `subm_…` key, ensure it has not been revoked, and confirm the base URL matches your SteadyRenew origin (not `/docs`) |
| `403 insufficient_scope` | The key is read-only (`read`); create a **Read & write** key to add, edit, or delete records |
| `403 premium_required` | `find_duplicate_subscriptions` and `get_optimization_suggestions` require Lifetime Premium; `list_subscriptions` and `get_spend_summary` work on Free |
| `429 rate_limit_exceeded` | Wait for the number of seconds in the `Retry-After` response header |
| HTML returned instead of JSON | Check your base URL; when testing locally, run `npm run dev:full` (Netlify Dev) rather than `npm run dev` |
| Local stdio MCP tools do not appear | Verify Node.js 20+ (`node -v`), use an absolute path to `steadyrenew-mcp.mjs` (not `~`), and restart/reload your MCP client |

## Machine-readable entry points

Hosted on the **application origin** (`https://steadyrenew.com` in production):

- `/api/mcp` — Stateless Streamable HTTP MCP endpoint (`POST` with Bearer `subm_…`).
- `/downloads/steadyrenew-mcp.mjs` — Zero-dependency single-file local stdio MCP server.
- `/downloads/subscription-manager-mcp.tgz` — Standalone npm tarball MCP package.
- `/agent/setup.md` — Step-by-step agent onboarding & client configuration reference.
- `/agent/ai-tools.json` — Canonical 11-tool JSON schema with risk & confirmation metadata.
- `/agent/openapi.yaml` — OpenAPI 3.1 specification for `/api/v1/*`.
