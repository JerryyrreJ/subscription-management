# Developer API keys

Developer API keys (`subm_…`) let trusted MCP clients, scripts, and automations access your SteadyRenew account through both the remote MCP endpoint (`/api/mcp`) and the `/api/v1/*` REST API.

## When to use an API key

Use an API key when you want an AI assistant, CLI tool, or script to:

- List and filter subscriptions or free trials.
- Summarize multi-currency spending (`get_spend_summary`).
- Detect duplicate subscriptions or surface annual-billing optimization candidates (requires **Lifetime Premium**).
- Create, update, or delete tracked subscriptions after confirmation (requires a **Read & write** key).
- Toggle global reminder settings (`enabled` and `daysBefore`) or inspect the API audit log.

Never embed API keys in public browser apps or untrusted shared prompts.

## Create and test a key

1. Sign in to SteadyRenew.
2. Open **Settings → API & MCP**.
3. Enter a descriptive key name (for example, `Claude Desktop` or `Claude Code`).
4. Choose **Read & write** or **Read only** permissions.
5. Click **Create key** and save the full `subm_…` secret immediately — SteadyRenew stores only its SHA-256 hash and shows the full key once.
6. Use [Copy to Agent](/en/user-guide/agent-setup) (or **Manual client config**) to connect your client, and use **Test API connection** in the footer anytime to verify a new or saved key.

## Expiration & revocation

- **Keys never expire automatically** — they stay valid until you revoke them (or delete your account).
- Open **Settings → API & MCP** and click **Revoke** next to any key you no longer need. Revoked keys immediately stop working across both `/api/v1/*` and `/api/mcp`.

## Limits

All signed-in accounts (Free and Lifetime Premium) default to **5 active keys** and **60 requests per minute per account**, shared across active keys. Duplicate detection (`/api/v1/analytics/duplicates`) and optimization suggestions (`/api/v1/analytics/optimizations`) require Lifetime Premium (`403 premium_required` on Free).

## Safety tips

- Create one key per client or script so you can revoke each integration independently.
- Prefer **Read only** keys for assistants that only answer questions about your spending.
- Rotate a key immediately if it ever appears in terminal logs, screenshots, or shared chats.
