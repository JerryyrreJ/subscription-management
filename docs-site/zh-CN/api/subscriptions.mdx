# 订阅 CRUD

订阅 API 使用 camelCase 字段。服务端管理字段会在响应中返回，但不能出现在写请求里。

## 操作语义

| 操作 | 适用场景 | 风险 | AI 是否需要确认 |
| --- | --- | --- | --- |
| `GET /api/v1/subscriptions` | 查询、搜索、汇总、分析或识别订阅 | 低 | 不需要 |
| `GET /api/v1/subscriptions/{id}` | 已知 UUID，读取单条订阅 | 低 | 不需要 |
| `POST /api/v1/subscriptions` | 记录新订阅或免费试用 | 中 | 需要 |
| `PATCH /api/v1/subscriptions/{id}` | 修改可写字段 | 中 | 需要 |
| `DELETE /api/v1/subscriptions/{id}` | 永久删除本地追踪记录 | 高 | 需要 |

AI 集成在更新或删除前应先查询并确认目标订阅，除非用户已提供准确的订阅 UUID。写操作需要带 `write` 权限的 API Key；只读 Key 会收到 `403 insufficient_scope`。

## 分页

`GET /api/v1/subscriptions` 默认按创建时间倒序返回，支持两个可选查询参数：

| 参数 | 默认值 | 规则 |
| --- | --- | --- |
| `limit` | `50` | 每页数量，范围 1 到 100 |
| `offset` | `0` | 从开头跳过的记录数 |

响应中包含 `pagination` 对象。当 `hasMore` 为 `true` 时，用 `offset + limit` 获取下一页。

```json
{
  "data": [ /* ... */ ],
  "pagination": { "limit": 50, "offset": 0, "hasMore": false },
  "requestId": "request-..."
}
```

```bash
curl -H "Authorization: Bearer $SUBSCRIPTION_MANAGER_API_KEY" \
  "https://steadyrenew.com/api/v1/subscriptions?limit=50&offset=50"
```

超出范围的取值会返回 `400 invalid_pagination`。

## 过滤、排序与自动续费周期滚动

`GET /api/v1/subscriptions` 在分页之外，还支持以下可选过滤器和排序：

| 参数 | 规则 |
| --- | --- |
| `status` | `active`、`paused`、`cancelled` 之一 |
| `category` | 分类精确匹配，如 `Streaming` |
| `period` | `monthly`、`yearly`、`custom` 之一 |
| `isTrial` | `true`（仅返回免费试用）或 `false`（排除免费试用） |
| `q` | 对订阅名称不区分大小写搜索 |
| `expiringBefore` | `YYYY-MM-DD`；返回实际生效的 `nextPaymentDate` 在该日期当天或之前的记录 |
| `sort` | `createdAt`、`-createdAt`、`nextPaymentDate`、`-nextPaymentDate`、`amount`、`-amount`、`name`、`-name` 之一（默认 `-createdAt`，前缀 `-` 表示降序） |

> [!NOTE]
> **续费日期动态跨周期推进：** `GET /api/v1/subscriptions` 与 `GET /api/v1/subscriptions/{id}` 会自动将已过期的 `active` 非试用订阅按完整计费周期推进到当前周期的下次扣款日（与网页仪表盘和 Bark 定时提醒一致），并在执行 `expiringBefore` 过滤和 `sort=nextPaymentDate` 排序前生效。免费试用（`isTrial: true`）以及 `paused` / `cancelled` 记录绝不会自动顺延。

将 `status=active` 与 `expiringBefore` 组合即可回答「哪些即将续费」。非法取值返回 `400 invalid_query`，并带 `field` 与 `suggestedFix`。

```bash
curl -H "Authorization: Bearer $SUBSCRIPTION_MANAGER_API_KEY" \
  "https://steadyrenew.com/api/v1/subscriptions?status=active&expiringBefore=2026-07-01&sort=nextPaymentDate"
```

响应会回显实际生效的查询，便于 Agent 确认结果来源：

```json
{
  "data": [ /* ... */ ],
  "pagination": { "limit": 50, "offset": 0, "hasMore": false },
  "query": { "sort": "nextPaymentDate", "filters": { "status": "active", "expiringBefore": "2026-07-01" } },
  "requestId": "request-..."
}
```

## 订阅对象

```json
{
  "id": "33333333-3333-4333-8333-333333333333",
  "name": "Netflix",
  "category": "Streaming",
  "amount": 15.99,
  "currency": "USD",
  "period": "monthly",
  "lastPaymentDate": "2026-06-01",
  "nextPaymentDate": "2026-07-01",
  "billingAnchorDay": 1,
  "isTrial": false,
  "notificationEnabled": true,
  "status": "active",
  "createdAt": "2026-06-16T00:00:00.000Z",
  "updatedAt": "2026-06-16T00:00:00.000Z"
}
```

当 `isTrial` 为 `true` 时，对象还会包含 `"trialEndsOn": "YYYY-MM-DD"`；当 `period` 为 `"custom"` 时，包含 `"customDate": "<天数>"`。

## 可写字段

```json
{
  "name": "Netflix",
  "category": "Streaming",
  "amount": 15.99,
  "currency": "USD",
  "period": "monthly",
  "nextPaymentDate": "2026-07-01",
  "billingAnchorDay": 1,
  "isTrial": false,
  "notificationEnabled": true
}
```

服务端管理字段包括 `id`、`status`（网页端生命周期状态）、`createdAt` 和 `updatedAt`。不要在 `POST` 或 `PATCH` 请求里发送这些只读字段（发送 `status` 或 `id` 会返回 `400 invalid_subscription_field`）。

## 字段规则

| 字段 | 规则 |
| --- | --- |
| `name` | 必填，1–120 个字符 |
| `category` | 必填，1–80 个字符 |
| `amount` | 必填数字，范围 0 到 999999.99，最多 2 位小数（免费试用填写试用结束后的转正价格，未知可填 `0`） |
| `currency` | 必填，可选 `CNY`、`USD`、`EUR`、`JPY`、`GBP`、`AUD`、`CAD`、`CHF`、`HKD`、`SGD` |
| `period` | 必填，可选 `monthly`、`yearly`、`custom` |
| `nextPaymentDate` | 下次续费日期，格式为 `YYYY-MM-DD`（除非 `isTrial` 为 `true` 且已提供 `trialEndsOn`，否则必填；免费试用若同时传入两者则必须一致） |
| `billingAnchorDay` | 月付订阅可选，范围 1–31；通常根据 `nextPaymentDate` 自动推断 |
| `isTrial` | 可选布尔值（默认 `false`）；设为 `true` 表示一次性到期的免费试用 |
| `trialEndsOn` | 免费试用截止/首次扣款日（`YYYY-MM-DD`）；当 `isTrial` 为 `true` 时必填（若已传 `nextPaymentDate` 则默认与之对齐） |
| `customDate` | 仅当 `period` 为 `custom` 时必填，正整数天数字符串；`monthly` / `yearly` 请省略 |
| `notificationEnabled` | 可选布尔值，默认 `true` |
| `lastPaymentDate` | 已弃用的兼容输入；未提供 `nextPaymentDate` 时会转换为下次续费日期 |

`nextPaymentDate` 是权威的订阅计划日期。月付订阅通过 `billingAnchorDay` 保留原始日历日期，短月份只会临时落到月末，例如：1 月 31 日 → 2 月 28/29 日 → 3 月 31 日。如果服务是固定每 30 天扣费而非每月固定日扣费，请使用 `period: "custom"` 和 `customDate: "30"`。

### 免费试用（Free Trials）

记录尚未首次扣款的免费试用时，将 `isTrial` 设为 `true` 并传入 `trialEndsOn`（同时将 `nextPaymentDate` 设为同一天）：

```json
{
  "name": "Figma Professional",
  "category": "Design",
  "amount": 15,
  "currency": "USD",
  "period": "monthly",
  "isTrial": true,
  "trialEndsOn": "2026-07-10",
  "nextPaymentDate": "2026-07-10",
  "notificationEnabled": true
}
```

免费试用是一次性截止日期：`trialEndsOn` 过期后不会自动顺延到下个月，直到你手动转为正式订阅（`{"isTrial": false, "nextPaymentDate": "2026-08-10"}`）或删除记录。

## 状态 vs 删除

响应中会返回只读的 `status`（`active`、`paused`、`cancelled`），列表查询也可以按它过滤。公开 API **不能** 通过写入 `status` 来取消、暂停或恢复订阅，也不会替你在外部服务商处退订。

调用 `DELETE /api/v1/subscriptions/{id}` 会从你的订阅账本中永久移除该记录，并在[审计日志](/zh-CN/api/audit)中写入一条包含 `metadata.before` 快照的 `subscription.delete` 记录。

在[分析](/zh-CN/api/analytics)端点中，只有 `active` 订阅计入活跃支出。

## 自然语言示例

### 新增订阅

用户意图：

```text
帮我记录 ChatGPT Plus，每月 20 美元，下次续费是 2026-07-17。
```

API 调用：

```bash
curl -X POST \
  -H "Authorization: Bearer $SUBSCRIPTION_MANAGER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"ChatGPT Plus","category":"AI","amount":20,"currency":"USD","period":"monthly","nextPaymentDate":"2026-07-17","notificationEnabled":true}' \
  https://steadyrenew.com/api/v1/subscriptions
```

### 修改计费周期

用户意图：

```text
把 Netflix 改成年付。
```

Agent 流程：

1. 调用 `GET /api/v1/subscriptions` 找到 Netflix 记录。
2. 向用户确认具体记录和修改内容。
3. 调用 `PATCH /api/v1/subscriptions/{id}`。

```bash
curl -X PATCH \
  -H "Authorization: Bearer $SUBSCRIPTION_MANAGER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"period":"yearly"}' \
  https://steadyrenew.com/api/v1/subscriptions/33333333-3333-4333-8333-333333333333
```

### 删除重复记录

用户意图：

```text
删除重复的 Netflix 订阅。
```

Agent 流程：

1. 调用 `GET /api/v1/subscriptions` 找到重复候选。
2. 向用户确认订阅名称和 id。
3. 调用 `DELETE /api/v1/subscriptions/{id}`。

```bash
curl -X DELETE \
  -H "Authorization: Bearer $SUBSCRIPTION_MANAGER_API_KEY" \
  https://steadyrenew.com/api/v1/subscriptions/33333333-3333-4333-8333-333333333333
```

## 自定义计费周期

如果不是月付或年付，把 `period` 设为 `custom`，并把 `customDate` 设为表示天数的正整数字符串。

```json
{
  "name": "Domain renewal",
  "category": "Infrastructure",
  "amount": 12,
  "currency": "USD",
  "period": "custom",
  "nextPaymentDate": "2026-07-16",
  "customDate": "45"
}
```

固定每 30 天续费时，把 `customDate` 设为 `"30"`；不要选择 `monthly`。从 `custom` 改回 `monthly` 或 `yearly` 时省略 `customDate`，服务端会自动清理旧的自定义计费数据。
