# Subscription Manager

Subscription Manager 帮你管理周期性订阅：付了哪些服务、多久续一次费、下次扣款是什么时候、按你选定的币种算下来一共花多少钱。

数据默认保存在你的浏览器里，不注册账号也能完整使用。需要多设备同步时，登录账号即可开启云端同步。

## 可以做什么

- 记录订阅名称、分类、金额、币种、计费周期和续费日期。
- 按基础币种查看月度和年度支出。
- 在 CNY、USD、EUR、JPY、GBP、AUD、CAD、CHF、HKD 和 SGD 之间换算。
- 按名称、金额、续费日期、分类或创建时间排序筛选。
- 管理内置分类和自定义分类。
- 使用 AI 录入，从一段文字或一张截图中自动新增、修改订阅。
- 通过 JSON 导入和导出订阅数据，随时备份或迁移。
- 登录账号后在多台设备间同步数据。
- 通过 Bark 接收续费推送提醒。
- 创建 Developer API Key，用开放 API 做自动化。
