# 开发者 API Key

Developer API Key（`subm_…`）可让受信任的 MCP 客户端、脚本和自动化工具通过远程 MCP 端点（`/api/mcp`）或 `/api/v1/*` REST API 安全访问你的 SteadyRenew 账户。

## 适用场景

当你希望 AI 助手、命令行工具或脚本执行以下任务时，可创建 API Key：

- 查询、过滤订阅与免费试用记录。
- 按币种和分类汇总支出（`get_spend_summary`）。
- 检测重复订阅或查看月付转年付优化候选（需**终身高级版**）。
- 在征得确认后新增、修改或删除追踪记录（需**读写**权限密钥）。
- 开关全局提醒设置（`enabled` 与 `daysBefore`）或读取开放 API 审计日志。

请勿将 API Key 放入公开前端代码或不受信任的共享提示词中。

## 创建与测试 Key

1. 登录 SteadyRenew。
2. 打开 **设置 → API 与 MCP**。
3. 输入便于识别的名称（例如 `Claude Desktop` 或 `Claude Code`）。
4. 选择 **读写** 或 **仅读取** 权限。
5. 点击创建并立即保存完整的 `subm_…` 密钥——服务端仅保存 SHA-256 哈希，完整明文只显示一次。
6. 使用[复制给 Agent](/zh-CN/user-guide/agent-setup)（或展开**手动配置客户端**）完成接入；也可随时在页脚通过 **测试 API 连接** 校验新密钥或已保存的密钥。

## 有效期与撤销

- **API Key 不会自动过期**——在你手动撤销（或注销账号）之前持续有效。
- 打开 **设置 → API 与 MCP**，对不再使用的密钥点击**撤销**即可立即使其在 `/api/v1/*` 与 `/api/mcp` 上失效。

## 配额与套餐说明

所有已登录账户（Free 与终身高级版）默认均支持最多 **5 个有效密钥**及**每账户每分钟 60 次请求**（多密钥共享）。其中 `/api/v1/analytics/duplicates` 与 `/api/v1/analytics/optimizations` 两个高阶分析端点需要终身高级版（Free 账户返回 `403 premium_required`）。

## 安全建议

- 为每个客户端或脚本单独创建专用 Key，便于独立撤销。
- 只用于查询和统计分析的助手优先选择**仅读取**权限。
- 一旦密钥可能出现在日志、截图或公开对话中，请立即撤销并重新创建。
