# 常见问题

## 我的数据存在哪里？

未登录时，所有订阅、分类和偏好设置保存在当前设备浏览器的本地存储中。登录账号后，数据会同步到你的云端账户下，方便在多台设备之间使用。

## 必须注册账号吗？

不需要。不登录即可完整使用订阅记录、多币种月度/年度概览、自定义分类、深色模式以及 JSON 导入导出。只有在需要多设备云同步、Passkey 通行密钥、AI 录入、Bark 服务端推送提醒、终身高级版或 Developer API / MCP 时才需要登录。

## Free 免费版与 Lifetime Premium 终身高级版有什么区别？

- **Free（\$0）**：不限数量的订阅与免费试用记录、本地优先 + 多设备云同步、Bark 续费提醒、**每月 10 次 AI 录入**、JSON 导入导出，以及完整的开放 API 与 MCP 接入（5 个有效 Key、每分钟 60 次请求，含 `get_spend_summary` 支出汇总）。
- **Lifetime Premium（\$9 USD 一次性买断，非订阅制）**：包含免费版全部功能，并解锁**每月 300 次 AI 录入**、**高级报表**与可直接打印的 **A4 PDF 导出**（快照与年度报告），以及开放 API / MCP 的重复订阅检测与优化建议高阶分析工具。

## SteadyRenew 会连接我的银行账户或替我退订服务吗？

不会。SteadyRenew 不读取银行卡或账单流水，也不会登录外部商户。在应用内（或通过 API / MCP）删除记录只会移除你的个人追踪条目——如需停止真实扣款，请前往服务商官网、App Store 或微信/支付宝的自动扣费管理页关闭服务。

## 免费试用和普通周期订阅有什么区别？

普通活跃订阅在扣款日过后会按月/年/自定义周期自动推进下次续费日期；而标记为**免费试用**的记录使用一次性到期日，过期后**不会自动顺延**，会一直保留到期提示，直到你手动转为正式订阅或删除记录。

## AI 录入会保存我的截图或粘贴文本吗？

不会。你提交的文本或截图仅在本次解析时发送给模型供应商一次，SteadyRenew 服务端不保存、不记录任何原始内容，只记录月度成功次数和聚合预算 token 计数。

## 为什么 Bark 续费提醒需要登录账号？

Bark 提醒由服务端定时任务触发，这样即使你关掉了电脑或浏览器，iPhone / iPad 依然能准时收到推送。登录并同步后，服务端才能将你的订阅列表与 Bark 设备地址关联起来。

## 为什么切换币种后总支出会变化，或提示离线汇率？

仪表盘会按实时汇率将不同币种的订阅换算成你选定的基础币种（断网时自动使用缓存或内置备用汇率），因此换算总额会随汇率波动，但每条订阅保存的原始计费币种和金额不会改变。

## 如何备份数据或迁移到新浏览器？

打开 **设置 → 通用**，在旧浏览器点击 **导出数据** 下载 JSON 备份文件，再在新浏览器点击 **导入数据** 即可恢复。
