# 订阅管理

订阅记录可用于管理流媒体、软件、云服务、会员、域名等周期扣费项目，也可以记录尚未正式扣款的**免费试用**，以便在自动转正前及时处理。

## 添加订阅

1. 点击 **添加订阅**。
2. 输入订阅名称并选择（或新建）分类。
3. 输入金额和计费币种。
4. 选择付款周期：**每月**、**每年**或**自定义**。
5. 选择**下次续费日期**（若是试用期服务，可开启**免费试用**并填写**试用到期日**）。
6. 选择是否为该订阅开启 Bark 推送提醒。
7. 保存订阅。

对于处于活跃状态的常规订阅，当续费日期过去后，应用会按计费周期自动推进下次续费日，同时保留原有的账单锚点规则。

## 记录免费试用（Free Trial）

添加或编辑尚未首次扣款的服务时，开启**免费试用**开关：

- 填写**试用结束 / 首次扣款日期**以及转正后的价格（若仅需到期提醒也可填 `0`）。
- 与常规订阅不同，**免费试用过期后绝不会自动顺延到下一周期**，而是保持到期提示状态，方便你在服务商处退订后将其删除/标记取消，或手动转为正式付费订阅。
- 开启 Bark 提醒后，系统会在试用到期前发送专属的试用到期推送。

## 付款周期

| 周期 | 适用场景 |
| --- | --- |
| 每月 | 每个月在固定日历日期扣费的服务 |
| 每年 | 每年固定日期扣费一次的服务 |
| 自定义 | 每隔固定天数（如每 30 天、每 45 天）扣费的服务 |

### “每月”按日历月份锚定

“每月”按每月同一个日历日续费（随大月、小月为 28–31 天）。若原始扣款日为 31 日，遇到短月份会临时落在该月最后一天，下个大月自动恢复为 31 日：

```text
1 月 31 日 → 2 月 28 日（闰年 29 日）→ 3 月 31 日
```

如果服务严格按“每隔 30 天”扣费，请选择**自定义**并填写 `30`。

## 编辑、暂停与取消状态

在列表中打开任意订阅即可修改名称、分类、金额、币种、周期、下次续费日、免费试用状态或提醒开关。

在网页端还可以将订阅标记为**已暂停（Paused）**或**已取消（Cancelled）**——保留历史记录的同时，不再计入当前活跃月度/年度支出，也不会触发 Bark 推送提醒。

## 筛选和排序

在仪表盘顶部可以：

- 在月度与年度总支出视图之间切换。
- 切换展示所用的基础币种。
- 按分类或状态筛选。
- 按金额、名称、分类、下次付款日期或创建时间升序/降序排列。

## 删除订阅

不再需要保留某条追踪记录时可选择**删除**。无论是网页端还是通过开放 API / MCP 删除，都只会移除 SteadyRenew 账本中的记录，**不会**自动替你在商户官网、App Store 或微信/支付宝中关闭真实自动扣费。
