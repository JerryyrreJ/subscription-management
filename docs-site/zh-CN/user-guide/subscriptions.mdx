# 订阅管理

订阅记录适合管理流媒体、软件、云服务、会员、域名，或者任何你想持续追踪的周期性付款。

## 添加订阅

1. 点击 **添加订阅**。
2. 输入订阅名称。
3. 选择分类，或添加新分类。
4. 输入金额和货币。
5. 选择付款周期：每月、每年或自定义。
6. 输入下次续费日期。
7. 选择是否为这个订阅启用通知。
8. 保存订阅。

下次续费日期是订阅计划的权威日期。应用会按照付款周期自动推进，同时保留原来的续费规则。

## 付款周期

| 周期 | 适合什么 |
| --- | --- |
| 每月 | 每个月在固定日历日期续费的服务 |
| 每年 | 每年续费一次的服务 |
| 自定义 | 每隔固定天数续费的服务 |

### “每月”按照日历月份计算

“每月”并不等于固定 30 天，而是每个月在同一个日历日期续费。因此一个月度周期可能是 28、29、30 或 31 天。例如锚定在 21 日的订阅，会一直在每月 21 日续费。

如果短月份里没有对应日期，应用会暂时使用当月最后一天，并在之后恢复原日期。例如：

```text
1 月 31 日 → 2 月 28 日（闰年为 29 日）→ 3 月 31 日
```

如果某项服务不是按每月固定日期，而是每隔 30 天扣费，请选择 **自定义**，并填写 `30`。这种订阅的续费日期可能会在不同月份之间移动。

其它自定义周期同样填写间隔天数。例如每 45 天扣费一次，就填写 `45`。

## 编辑订阅

从列表打开一个订阅，然后选择编辑。你可以修改名称、分类、金额、币种、付款周期、下次续费日期、自定义周期和通知设置。

修改下次续费日期后，应用也会更新未来月度续费使用的固定日期。

## 筛选和排序

在概览区域可以：

- 在月度和年度总支出之间切换。
- 切换基础币种。
- 按分类筛选。
- 按金额、名称、分类、续费日期或创建时间排序。
- 切换升序或降序。

## 删除订阅

打开订阅详情后，可以删除不再需要追踪的订阅。删除会把记录从你的列表中移除。

如果你通过开放 API 使用应用，也可以用取消或暂停状态保留历史；在应用界面中，删除是主要的移除操作。
