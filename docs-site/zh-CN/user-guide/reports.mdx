# 报表与 PDF 导出

高级报表把你的订阅列表变成支出分析：总额、分类构成、支出排行和续费节奏。可以在应用内查看，也可以导出为可直接打印的 A4 PDF。

## 打开高级报表

1. 打开仪表盘。
2. 选择**查看高级报表**。

报表使用当前的基础币种和汇率。其他币种计费的订阅会换算成基础币种参与统计和对比。

## 导出 PDF

高级报表顶部提供两种导出：

- **导出快照（1 页）**——当前支出的紧凑摘要：月度和年化总额、分类构成、完整订阅表格，以及未来 30 天的扣款。
- **导出年度报告**——年度视角：逐月支出趋势、支出排行前列的订阅和分类合计。

选择导出后，浏览器会打开打印对话框，报表已按 A4 排好版。选择**存储为 PDF**（或打印机）即可完成。

## 说明

- 报表完全在浏览器内生成，生成 PDF 时订阅数据不会离开你的设备。
- 导出跟随应用语言，同一份报表有中英文两个版本。
- 逐月支出趋势由当前订阅及其创建时间回溯推算，不是真实账单历史。
- 页脚会记录导出日期和换算所用的汇率快照。
