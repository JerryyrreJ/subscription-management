# 报表与 PDF 导出

SteadyRenew 仪表盘免费提供按基础币种汇总的月度与年度支出概览。升级**终身高级版（\$9 USD 一次性买断）**后，即可解锁**高级报表（Advanced Report）**完整分析视图与 **A4 PDF 报表导出**（同时解锁开放 API / MCP 的重复检测与优化建议工具）。

## 打开高级报表

1. 登录已开通**终身高级版**的账号。
2. 在仪表盘点击**查看高级报表**。

高级报表会按当前选定的基础币种与汇率，将多币种订阅统一换算后进行趋势、构成与排行对比。

## 导出 PDF

高级报表顶部提供两种排版导出：

- **导出快照**——当前支出的紧凑摘要：月度与年化总额、分类构成、完整订阅明细表以及未来 30 天即将到期的扣款。超过一页 A4 时会自动分页续排。
- **导出年度报告**——年度视角：逐月支出趋势、支出排行前列的订阅与分类年度合计，明细过长时自动跨页排版。

点击导出后会唤起浏览器打印对话框（已按标准 A4 尺寸排版），选择**存储为 PDF**（或连接打印机）即可完成导出。

## 说明

- PDF 报表完全在本地浏览器中生成，订阅明细不会上传到任何外部渲染服务器。
- 导出内容跟随当前界面语言（支持简体中文与英文）。
- 逐月支出趋势基于当前追踪订阅及其创建日期推算，并非银行流水账单历史。
- 页脚会自动记录导出日期与换算所使用的汇率快照。
