# 账号和同步

SteadyRenew 采用本地优先设计。你可以不登录直接使用，也可以登录账号以开启多设备云同步及云端功能（AI 录入、Bark 定时提醒、终身高级版与 Developer API / MCP 密钥）。

## 不登录使用

未登录时，数据保存在当前浏览器本地存储中，简单私密；但如果清理浏览器站点数据或更换设备，记录不会自动迁移，建议定期导出 JSON 备份。

## 登录方式与 Passkey 通行密钥

点击 **登录后同步**（或右上角账号菜单）即可登录，支持：

- **邮箱与密码**
- **Passkey 通行密钥（WebAuthn）**——绑定后可使用 Face ID、Touch ID、Windows Hello 或硬件安全密钥免密登录
- **第三方 OAuth 登录**（视部署环境配置而定）

登录后，应用会自动将你的订阅、免费试用、自定义分类与 Bark 提醒设置同步到当前账号下。

## 同步状态

用户菜单会实时显示同步状态（同步中、上次同步时间、同步失败或尚未同步），需要时可点击 **立即同步** 手动触发。

## 账号设置

打开 **设置 → 账号** 可以管理：

- 昵称
- 邮箱地址
- 登录密码
- **Passkey 通行密钥**（注册新通行密钥或移除已有设备）
- 永久注销账号（**危险操作**）

## 注销账号

打开 **设置 → 账号 → 危险操作** 可永久注销账号。注销会立即删除登录凭证、通行密钥、个人资料、云端订阅、分类、通知设置、Developer API Key、Premium 状态以及当前设备浏览器中属于该账号的数据，操作不可撤销。

注销账号不会自动触发退款。若账号存在历史购买记录，系统会将支付记录与 `user_id` 解绑，仅在法定期限内保留对账、退款及争议处理所必需的付款邮箱与 Stripe 交易字段，绝不用于营销。

服务端无法远程擦除你在其他设备浏览器中已缓存的本地副本，如有需要请一并在其他设备上清除本站浏览器数据。
