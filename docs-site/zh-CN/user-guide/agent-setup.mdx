# 连接 Agent

## 三步完成连接

<Steps>
  <Step title="创建 Developer API Key">
    登录网页端，打开 **设置 → API 与 MCP**，为你的助手创建一个专用密钥：
    需要增删改查订阅时选择 **读写**；仅用于查询与支出分析时选择 **仅读取**。
    完整的 `subm_…` 密钥只展示一次，且**不会自动过期**（除非手动撤销）。
  </Step>
  <Step title="复制给 Agent（或复制手动配置片段）">
    选择 **MCP · 推荐** 或 **仅使用 API**，点击 **复制给 Agent**。
    默认提示词不包含密钥；刚创建密钥后，也可以勾选 **在本次复制中附带新建密钥** 粘贴给你信任的 Agent。
    如果你想手动写入客户端配置文件，展开同一卡片下方的 **手动配置客户端** 即可直接复制 Claude Code、Claude Desktop、Cursor 和 Codex 的配置片段。
  </Step>
  <Step title="验证连接">
    让 Agent 列出你的订阅以验证连通性（只读查询，不会写入测试垃圾数据；空列表同样代表连接成功）。
    你也可以在 **设置 → API 与 MCP** 页脚直接点击 **测试 API 连接** 校验新密钥或已保存的密钥——测试成功后会立即刷新该密钥的**最近使用**时间。
  </Step>
</Steps>

连接成功后，可以直接用自然语言提问或操作：

- *“未来 14 天有哪些订阅或免费试用要到期？”*
- *“按币种和分类汇总我每月的订阅支出。”*
- *“帮我添加 ChatGPT Plus，每月 \$20，下次续费 2026-07-17。”*（使用读写密钥时，Agent 会先总结变更并请你确认。）
- *“删除重复的 Netflix 记录。”*（使用读写密钥时，Agent 会先核对准确名称与 `id`。）

## 三种接入方式怎么选

| 接入方式 | 推荐客户端 | 工作方式 |
| --- | --- | --- |
| **远程 Streamable HTTP MCP**（`/api/mcp`） | Claude Code、Cursor 远程 MCP、ChatGPT / 网页版 Claude 连接器 | 直接连接 `https://steadyrenew.com/api/mcp`（携带 `Authorization: Bearer subm_…`），**零本地安装、无需 Node.js** |
| **本地单文件 stdio MCP**（`/downloads/steadyrenew-mcp.mjs`） | Claude Desktop、Cursor 本地 stdio、Codex（`config.toml`）、OpenCode | 下载单个零依赖 `.mjs` 文件（需 Node.js 20+），通过 `node` 与 `SUBSCRIPTION_MANAGER_API_KEY` 启动 |
| **直接调用 `/api/v1` REST API** | 定时脚本、自建后端、仅支持 HTTP 请求的 Agent | 参考 `/agent/openapi.yaml` 与 `/agent/ai-tools.json` 直接发送 HTTP 请求 |

> [!TIP]
> **设置 → API 与 MCP** 上的**下载 MCP** 仍提供兼容旧版的独立 npm 包（`/downloads/subscription-manager-mcp.tgz`）。对于绝大多数本地 stdio 客户端，直接下载单文件脚本（`curl -fsSL https://steadyrenew.com/downloads/steadyrenew-mcp.mjs -o ~/.steadyrenew/mcp/steadyrenew-mcp.mjs`）更轻量，也能避免 npm workspace 安装报错。

## 套餐限额与权限边界

- **配额与有效期限**：Free 与 Premium 账户默认均为最多 **5 个有效密钥**、**每账户每分钟 60 次请求**（多密钥共享），且密钥永不自动过期。
- **只读密钥感知**：创建时选择**仅读取**会生成 `["read"]` 密钥，**复制给 Agent** 也会自动生成只读引导说明，避免 Agent 尝试写操作。
- **高级版分析工具**：`get_spend_summary` 在所有套餐下均可用；`find_duplicate_subscriptions` 与 `get_optimization_suggestions` 需**终身高级版**（Free 账户返回 `403 premium_required`）。
- **仅限网页端管理的操作**：删除追踪记录绝不会替你在商户处退订真实扣款；Bark 推送 URL、测试推送、`timeZone`、`locale` 和分类目录管理仍在网页端完成（见[续费提醒指南](/zh-CN/user-guide/reminders)）。

## 常见问题排查

| 现象 | 处理方式 |
| --- | --- |
| `401`（`authentication_required` / `invalid_api_key`） | 检查是否完整复制了 `subm_…` 密钥、是否已撤销，以及 Base URL 是否为应用主站地址（不要填 `/docs`） |
| `403 insufficient_scope` | 当前使用的是只读密钥；如需新增、修改或删除，请创建**读写**密钥 |
| `403 premium_required` | 重复订阅检测与优化建议需要终身高级版；基础增删改查和 `get_spend_summary` 在 Free 下可正常使用 |
| `429 rate_limit_exceeded` | 按响应头 `Retry-After` 提示的秒数等待后再重试 |
| 返回 HTML 而非 JSON | 检查站点地址是否正确；本地联调 Functions 时需运行 `npm run dev:full` 而非 `npm run dev` |
| 本地 stdio MCP 工具未显示 | 确认已安装 Node.js 20+（`node -v`），配置中使用 `steadyrenew-mcp.mjs` 的**绝对路径**（不要用 `~`），并重启客户端 |

## 面向 Agent 的机器可读入口

以下路径均挂载在**应用主域名**下（生产环境为 `https://steadyrenew.com`）：

- `/api/mcp`：无状态远程 Streamable HTTP MCP 端点（使用 Bearer `subm_…` 发送 `POST` 请求）。
- `/downloads/steadyrenew-mcp.mjs`：零依赖单文件本地 stdio MCP 脚本。
- `/downloads/subscription-manager-mcp.tgz`：独立 npm `.tgz` MCP 安装包。
- `/agent/setup.md`：完整的 Agent 接入、客户端配置与错误恢复指南。
- `/agent/ai-tools.json`：包含风险等级与写确认规则的 11 个工具 JSON 定义。
- `/agent/openapi.yaml`：`/api/v1/*` 开放 API 的 OpenAPI 3.1 规范。
