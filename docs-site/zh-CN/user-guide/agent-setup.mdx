## 三步连接

<Steps>
  <Step title="创建密钥">
    登录网站，打开 **设置 → API & MCP**，为你的 Agent 创建一个单独的密钥。
    选择 **读写** 可以查询、新增、修改和删除订阅；只需要查看时选择 **只读**。
    完整密钥只显示一次，请保存在私有位置。
  </Step>
  <Step title="复制给 Agent">
    在页面顶部选择 **MCP · 推荐** 或 **仅使用 API**，点击 **复制给 Agent**。
    把说明粘贴给能够配置本地工具或调用 HTTP 接口的 Agent。
    默认说明不包含密钥，Agent 会引导你私下提供；新建密钥后，也可以勾选 **在本次复制中附带新建密钥**，只粘贴给你信任的 Agent。
    使用 **预览说明** 可以检查实际复制内容。
  </Step>
  <Step title="验证连接">
    Agent 会读取一条订阅验证连接，不会创建测试数据。没有订阅的空列表也表示成功。
    页面上的 **测试 API 连接** 只能验证密钥和 API；Agent 仍需完成自己的连接测试。
    如果客户端需要重启，重启后让 Agent 再查询一次。
  </Step>
</Steps>

连接后，可以直接说：

- “列出我的所有订阅。”
- “帮我添加一个每月 20 美元的订阅。”（Agent 会继续询问名称、续费日期等必要信息。）
- “把 Netflix 的金额改成 25 美元。”
- “删除重复的订阅记录。”

写入前 Agent 应确认具体变更，删除前确认名称与 id。删除追踪记录不会向服务商退订。

## MCP 和 API 怎么选

| 方式 | 适用情况 | Agent 需要做什么 |
| --- | --- | --- |
| MCP（推荐） | 客户端支持本地 stdio MCP 服务器 | 检查 Node.js 20+，下载安装包，安装并合并配置，然后调用工具验证 |
| API | Agent 可以发送带密钥的 HTTP 请求 | 读取 API 定义，保存私有密钥并验证查询；无需安装 MCP |

**下载 MCP** 提供独立的 npm `.tgz` 安装包，内含服务器与工具定义。它随当前网站发布，无需克隆源码或等待 npm 公共包发布。只支持远程 MCP URL 的客户端不能把下载地址作为 MCP 服务地址；当前没有托管的远程 MCP 端点。

如果 Agent 既不能运行本地工具，也不能调用 HTTP 接口，仅复制提示词还不足以完成连接。

## 已有密钥、自托管和本地数据

- 可以复制不含密钥的说明，使用已保存在私有环境中的密钥；无需每次创建新密钥。
- 旧密钥只显示前缀，无法从前缀恢复完整密钥。遗失后创建新密钥并撤销旧密钥。
- 设置页自动使用当前网站地址，自托管实例也适用。不要将文档站地址作为 API 地址。
- 只读取当前账户的云端订阅；浏览器本地记录需要先同步到该账户。
- 同一账户默认最多 5 个有效密钥、每分钟 60 次请求，所有密钥共享限流。以设置页的实际限额为准。

## 连接不成功时

| 现象 | 处理方式 |
| --- | --- |
| 401 / 密钥无效 | 检查是否复制了完整密钥、是否已撤销、网站地址是否正确 |
| 403 `insufficient_scope` | 当前是只读密钥；修改订阅需要读写密钥 |
| 部分高级分析返回 403 | 根据错误检查 Premium 权益；基础增删查改无需 Premium |
| 429 | 等待响应中的 `Retry-After` 指定时间后重试 |
| 返回网页而不是 JSON | 检查 API 部署；本项目本地调试需使用 `npm run dev:full` |
| MCP 配置已写入但工具不可用 | 检查 Node 路径与服务器绝对路径，重载客户端后调用工具验证 |
| 剪贴板不可用 | 展开预览并手动选中复制 |

Bark 地址、测试推送、时区、语言与分类目录仍在网页中管理。详见[提醒指南](/zh-CN/user-guide/reminders)和 [AI 工具说明](/zh-CN/api/ai-tools)。

## 给 Agent 的机器可读入口

以下路径均位于**应用网站**上：

- `/agent/setup.md`：安装、配置、验证与错误恢复步骤。
- `/agent/ai-tools.json`：工具及参数定义。
- `/agent/openapi.yaml`：开放 API 定义。
- `/downloads/subscription-manager-mcp.tgz`：独立 MCP 安装包。

这些文件不包含账户密钥。具体网站地址由设置页生成的提示词提供。
