# 使用 Bark 续费提醒

SteadyRenew 通过开源 iOS 推送工具 [Bark](https://apps.apple.com/app/bark-customed-notifications/id1403753865) 向 iPhone 和 iPad 发送服务端续费与免费试用到期提醒。托管提醒流程基于 Netlify Scheduled Function 和 Supabase 存储的通知设置运行，无需保持浏览器打开。

## 用户端配置项

登录用户在网页端 **设置 → 通知** 中配置（使用步骤见[续费提醒指南](/zh-CN/user-guide/reminders)）：

- Bark 推送 URL（自动解析服务器地址与 device key）。
- 全局提醒开关（`enabled`）与提前提醒天数（`1`、`3`、`7` 或 `14` 天）。
- 单条订阅的提醒开关（`notificationEnabled`）。

## 触发规则与免费试用处理

- 仅当订阅状态为 **`active`** 且开启了 `notificationEnabled: true` 时才会发送推送；**`paused`**（已暂停）和 **`cancelled`**（已取消）的订阅始终跳过。
- **常规周期订阅**：在评估提醒窗口前会自动把已过期的 `nextPaymentDate` 推进到当前计费周期。
- **免费试用（`isTrial: true`）**：按一次性的 `trialEndsOn`（试用到期 / 首次扣款日）触发试用到期专属文案提醒，方便及时退订或保留；到期后不会自动顺延。

## 必需服务与环境变量

- Supabase（`VITE_SUPABASE_URL`、`VITE_SUPABASE_ANON_KEY`、`SUPABASE_SECRET_KEY`）。
- Netlify Scheduled Functions。
- Bark 官方服务器（`https://api.day.app`）或公网可达的 HTTPS 自托管 Bark 服务。

## SQL 迁移

通知配置表、防重发送锁与免费试用字段包含在 `supabase/migrations/` 中（核心迁移包括 `20260615000100_baseline.sql`、`20260615000200_harden_existing_schema.sql` 与 `20260916000100_subscription_trials.sql`）。

## 定时函数与本地测试

定时任务位于 `netlify/functions/send-scheduled-notifications.ts`，会按每位用户的 `timeZone` 计算即将到期的订阅、发送对应语言的 Bark 推送、记录发送历史并通过发送锁防止重复推送。

本地测试命令：

```bash
npm run test:notifications
npm run dev:full
```
