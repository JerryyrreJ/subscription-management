# 配置说明

核心应用不需要任何环境变量即可运行。仅在需要启用可选云服务时按需添加对应变量；仓库根目录提供了 `.env.example` 模板。

## 环境变量一览

| 变量 | 用途 | 作用域 |
| --- | --- | --- |
| `VITE_SITE_URL` | 公开首页、博客、canonical 链接以及 `/agent/*` schema 的站点域名（默认 `https://steadyrenew.com`） | 浏览器 / 构建 |
| `VITE_APP_URL` | 应用工作台入口路径或地址（同域部署使用 `/app`） | 浏览器 / 构建 |
| `VITE_DOCS_URL` | 多语言文档基础地址（默认 `https://steadyrenew.com/docs`） | 浏览器 / 构建 |
| `VITE_SUPABASE_URL` | Supabase 登录与云同步 | 浏览器 |
| `VITE_SUPABASE_ANON_KEY` | Supabase 登录与云同步 | 浏览器 |
| `SUPABASE_URL` | Netlify Functions 使用的 Supabase URL | 仅服务端 |
| `SUPABASE_PUBLISHABLE_KEY` | Functions 校验用户 access token | 仅服务端 |
| `SUPABASE_SECRET_KEY` | 定时提醒、付费激活、账号注销、开放 API / MCP 访问与 AI 录入配额 | 仅服务端 |
| `SUPABASE_SERVICE_ROLE_KEY` | `SUPABASE_SECRET_KEY` 的旧版兼容别名 | 仅服务端 |
| `VITE_STRIPE_PUBLISHABLE_KEY` | 启用前端支付入口，不作为结账授权依据 | 浏览器 |
| `STRIPE_SECRET_KEY` | 创建 Stripe Checkout 会话与支付状态对账 | 仅服务端 |
| `STRIPE_WEBHOOK_SECRET` | 校验 Stripe Webhook 签名 | 仅服务端 |
| `STRIPE_PRICE_ID` | 服务端唯一信任的 \$9 USD 一次性终身版 Stripe Price ID | 仅服务端 |
| `STRIPE_MODE` | 显式声明 Stripe 环境模式（生产为 `live`，预发/测试为 `test`）；模式不匹配时直接拒绝请求与回调 | 仅服务端 |
| `PRODUCTION_SUPABASE_URL` | 在预发/预览环境设置为生产 Supabase URL，防止测试支付写入生产数据库 | 仅服务端 |
| `SITE_URL` | 服务端可信站点地址，用于 Stripe 回调跳转与 Agent 交付物地址回退 | 仅服务端 |
| `URL` | Netlify 自动注入的当前部署地址 | Netlify 提供 |
| `MINTLIFY_UPSTREAM_ORIGIN` | `/docs` Edge 反向代理的可选自定义 Mintlify 上游域名 | Edge / 服务端 |
| `API_RATE_LIMIT_PER_MINUTE` | 每账户每分钟 API / MCP 已认证请求数（Free 与 Premium 相同），默认 `60` | 仅服务端 |
| `API_MAX_ACTIVE_KEYS` | 每账户最大有效 Developer API Key 数量（Free 与 Premium 相同），默认 `5` | 仅服务端 |
| `API_FAILED_AUTH_RATE_LIMIT_PER_HOUR` | 每个客户端身份每小时允许的最大失败 API Key 鉴权次数，默认 `300` | 仅服务端 |
| `API_RATE_LIMIT_RETENTION_HOURS` | 限流计数窗口被定时清理前的保留小时数，默认 `48` | 仅服务端 |
| `OPENROUTER_API_KEY` | 通过 OpenRouter 启用 AI 录入（推荐默认路径） | 仅服务端 |
| `ANTHROPIC_API_KEY` | 通过 Anthropic 启用 AI 录入 | 仅服务端 |
| `AI_PROVIDER` | 可选供应商覆盖：`openrouter` 或 `anthropic` | 仅服务端 |
| `AI_MODEL` | 主模型覆盖（OpenRouter 默认 `google/gemini-2.5-flash-lite`） | 仅服务端 |
| `AI_FALLBACK_MODELS` | 逗号分隔的 OpenRouter 备选模型（默认 `google/gemini-2.5-flash`） | 仅服务端 |
| `OPENROUTER_SITE_URL` | 可选 OpenRouter `HTTP-Referer` 请求头；默认回退到 `SITE_URL` 或 `URL` | 仅服务端 |
| `OPENROUTER_APP_TITLE` | 可选 OpenRouter `X-Title` 请求头（默认 `SteadyRenew`） | 仅服务端 |
| `AI_FREE_MONTHLY_PARSES` | Free 用户每月 AI 录入次数（仅成功解析计次），默认 `10`（兼容旧名 `AI_FREE_DAILY_PARSES`） | 仅服务端 |
| `AI_PREMIUM_MONTHLY_PARSES` | Premium 用户每月 AI 录入次数（仅成功解析计次），默认 `300`（兼容旧名 `AI_PREMIUM_DAILY_PARSES`） | 仅服务端 |
| `AI_MAX_INPUT_CHARS` | 单次 AI 录入文本最大字符数，默认 `20000` | 仅服务端 |
| `AI_MAX_IMAGE_BYTES` | 单次 AI 录入图片解码后最大字节数，默认 `4194304`（4 MB） | 仅服务端 |
| `AI_MONTHLY_BUDGET_USD` | 工作区级月度 AI 预算熔断上限（美元），默认 `50` | 仅服务端 |
| `AI_INPUT_USD_PER_MTOK` | 每百万输入 token 成本估算（默认 `0.1`） | 仅服务端 |
| `AI_OUTPUT_USD_PER_MTOK` | 每百万输出 token 成本估算（默认 `0.4`） | 仅服务端 |

## 浏览器变量

所有以 `VITE_` 开头的变量都会在构建时注入前端产物，请勿在其中放入任何服务端密钥。

Passkey 通行密钥不需要额外的 `VITE_*` 变量——只需在 Supabase Dashboard（本地开发为 `supabase/config.toml`）中启用，详见 [Supabase 集成](/zh-CN/integrations/supabase#passkeys-webauthn-通行密钥)。

## 服务端变量

服务端变量应配置在托管平台（如 Netlify Environment Variables）中，切勿提交 `SUPABASE_SECRET_KEY`、`STRIPE_SECRET_KEY`、`STRIPE_WEBHOOK_SECRET` 或模型供应商密钥。

Functions 优先读取 `SUPABASE_URL`、`SUPABASE_PUBLISHABLE_KEY`、`SUPABASE_SECRET_KEY` 和 `STRIPE_PRICE_ID`，同时兼容旧名 `VITE_SUPABASE_URL`、`VITE_SUPABASE_ANON_KEY`、`SUPABASE_SERVICE_ROLE_KEY` 和 `VITE_STRIPE_PRICE_ID`。

## 运行时功能检测

应用在运行时按已配置的环境变量启用对应模块：

- 配置 Supabase 后开启账号登录、Passkey、云同步与账号管理。
- 配置 Stripe 后开启终身高级版结账与支付状态对账。
- Developer API Key、`/api/v1/*` 与 `/api/mcp` 依赖 Supabase 与 Netlify Functions。
- AI 录入依赖 Supabase、Netlify Functions、执行至 `20260922000100_ai_monthly_quota.sql` 的数据库迁移，以及 `OPENROUTER_API_KEY` 或 `ANTHROPIC_API_KEY`。
- 缺少可选变量时，应用自动保持本地优先模式。

## Bark 通知设置

Bark 推送参数（服务器地址、device key、提前提醒天数及单条订阅开关）由用户在网页端 **设置 → 通知** 中自行配置。
