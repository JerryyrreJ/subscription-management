# 快速开始

SteadyRenew 基于 React、TypeScript 与 Vite 构建。默认情况下，所有数据保存在浏览器本地存储中，无需注册数据库或账号即可完整使用核心功能。

## 架构概览

```text
React + Vite 前端 (/app) + 预渲染公开页面 (/, /pricing, /blog)
  |
  | 可选的浏览器登录与云同步
  v
Supabase (Auth、Postgres + RLS、Passkeys 通行密钥)
  |
  | 可信服务端访问
  v
Netlify Edge Functions + Functions
  |-- Edge：smart-entry (/)、docs-proxy (/docs)
  |-- API Key 管理、开放 API (/api/v1/*)、远程 MCP (/api/mcp)
  |-- AI 录入 (/ai-parse-subscriptions)
  |-- Stripe Checkout、状态对账与 Webhook
  |-- 账号注销与定时 Bark 推送提醒
```

## 环境要求

- Node.js 22.12 或更高版本
- npm

## 克隆与安装

```bash
git clone https://github.com/JerryyrreJ/subscription-management.git
cd subscription-management
npm install
```

## 启动前端开发服务器

```bash
npm run dev
```

Vite 启动后，可在 `http://localhost:5173/app` 打开应用工作台（公开落地页位于 `http://localhost:5173/`）。

## 连同 Netlify Functions 一起运行

测试 Stripe 支付回调、AI 录入、开放 API（`/api/v1/*`）、远程 MCP（`/api/mcp`）或定时通知逻辑时，使用 Netlify Dev：

```bash
npm run dev:full
```

该命令依赖 Netlify CLI（默认监听 `http://localhost:8888`）。

## 常用命令

```bash
npm run build               # 构建前端、Agent/MCP 交付物及预渲染页面
npm run preview             # 预览生产构建产物
npm run lint                # 运行 ESLint 检查
npm run typecheck           # 运行前端、Functions 与构建脚本 TypeScript 类型检查
npm run test                # 运行工具函数与 SEO/博客测试
npm run test:functions      # 运行 Netlify Functions 与 Edge Functions 测试
npm run check               # 依次执行 typecheck、lint、test、test:functions 和 build
npm run db:verify           # 重置本地 Supabase、执行 schema lint 与 pgTAP 测试
npm run test:notifications  # 本地测试定时 Bark 通知逻辑
```

## 本地优先行为

未配置 Supabase 时，订阅、免费试用、分类、偏好设置与 JSON 导入导出数据全部留在浏览器中，依然可以记录订阅、筛选排序、切换币种、查看概览图表和深色模式。

云端能力按需开启：

| 能力 | 所需服务 |
| --- | --- |
| 账号登录、Passkey 通行密钥与多设备云同步 | Supabase |
| AI 录入（文本与截图解析） | Supabase + Netlify Functions + OpenRouter 或 Anthropic Key |
| 开放 API（`/api/v1/*`）与 MCP（`/api/mcp`） | Supabase + Netlify Functions |
| 续费与试用推送提醒 | Supabase + Netlify Scheduled Functions + Bark |
| 终身高级版支付与权益对账 | Supabase + Netlify Functions + Stripe |

下一步请查看[配置说明](/zh-CN/configuration)。
