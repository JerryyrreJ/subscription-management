# SteadyRenew 文档站 Mintlify 部署

`docs-site/` 是 SteadyRenew 唯一的公开文档源码目录，生产环境通过 `netlify/edge-functions/docs-proxy.ts` 挂载在 `https://steadyrenew.com/docs`。反向代理与截图重录细节见 [`docs-site/README.md`](../docs-site/README.md)。

## 本地结构

```text
docs-site/
  docs.json          # Mintlify 导航与中英双语配置
  api/openapi.yaml   # 开放 API OpenAPI 3.1 规范
  api/ai-tools.json  # AI / MCP 工具定义真源
  en/                # 英文文档
  zh-CN/             # 简体中文文档
```

## 更新与校验流程

当产品功能、开放 API、MCP、环境变量、Supabase schema、支付或通知逻辑变化时：

1. 同步更新 `docs-site/en/` 与 `docs-site/zh-CN/` 对应页面。
2. 如涉及接口或工具定义变更，同步更新 `docs-site/api/openapi.yaml` 与 `docs-site/api/ai-tools.json`。
3. 在 `docs-site/` 目录执行断链与构建校验：

```bash
cd docs-site
mint broken-links
mint validate
```

4. 在仓库根目录执行 `npm run check`（确保构建生成的 `/agent/*` 与 MCP 交付物同步更新）。
