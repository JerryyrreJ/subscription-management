# Deploy the SteadyRenew documentation site

`docs-site/` is the canonical public documentation source for SteadyRenew, served in production at `https://steadyrenew.com/docs` via `netlify/edge-functions/docs-proxy.ts`. See [`docs-site/README.md`](../docs-site/README.md) for proxy and asset capture details.

## Local preview & validation

```bash
npm i -g mint
cd docs-site
mint dev
```

Before pushing documentation changes, run both checks from `docs-site/`:

```bash
cd docs-site
mint broken-links
mint validate
```

## Mintlify project setup

1. Open `https://mintlify.com/start` and connect the `subscription-management` repository.
2. Enable subdirectory mode and set the documentation path to `docs-site`.
3. Configure custom domain subpath `steadyrenew.com/docs` in Mintlify while keeping root DNS on Netlify (add only Mintlify's TXT verification records).

## Agent-friendly outputs

Mintlify automatically serves per-page Markdown exports, `Accept: text/markdown`, `/docs/llms.txt`, and `/docs/llms-full.txt` alongside the app's own `/llms.txt` and `/agent/*` contracts.
